# Academic CV

`CV_Yuankai_Tao_Academic.tex` is an academic-oriented CV for applications to Lehigh University ISYE and related programs.

## How to use

Compile from this directory so the relative class-file path resolves:

```powershell
cd "e:\VS Code Projects\JobHuntBot\my-materials\Academic"
pdflatex -interaction=nonstopmode CV_Yuankai_Tao_Academic.tex
```

The CV is organized to foreground research experience, selected research projects, and research interests in machine learning, data science, and operations research. The source reuses verified content from `original_CV` and does not modify that directory.
