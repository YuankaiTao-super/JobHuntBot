# Tailored Resume Outputs

This private directory stores job-specific resume copies.

## Source protection

- Never modify, overwrite, rename, or delete anything in `../original_CV/`.
- Do not edit the reusable Quant, Risk, Data, or BA base files for a specific job.
- Copy the selected base `.tex` and required local dependencies into a company/role directory first.

## Layout

`<company-slug>/<role-slug>/CV_Yuankai_Tao_<Company>_<Role>_vNN.{tex,pdf}`

Create a new version number rather than overwriting an earlier tailored output.

## Tailoring boundary

Only reorder, tighten, emphasize, or add/remove keywords supported by verified experience. Never invent skills, metrics, credentials, employers, dates, or work authorization.
